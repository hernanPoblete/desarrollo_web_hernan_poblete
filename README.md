# Tarea 1

Esta tarea se basa en construir vistas para una aplicación que registre las diversas actividades de varios tipos de usuario.

Más adelante, se incorporarán funcionalidades desde el lado de backend.

De momento, la información acumulada puede resumirse en el siguiente diagrama entidad relación:

![Diagrama ER](./docs/content/T1/er_diagram(4).png)

## Decisiones relevantes de diseño para Tarea 1

- Se utiliza flexbox para entregar responsividad.
- Se utilizan clases de javascript en una variable global para hacer mock de la base de datos.
- Se utilizan opciones separadas en select para diferenciar estudiantes de pregrado y postgrado
- De momento, como el acceso a datos es puro mockup, se deja acceso a toda la información disponible. (Todos los datos y de todos los usuarios)
